# 个人手动启动分支

此分支保存Windows手动启动方案，供遇到卡巴斯基行为拦截、愿意取消开机自启动与后台守护任务的使用者参考。它不是已获杀毒软件认证的发行版，也不能保证其他机器不会报毒。

`feat/quota-step-reminders`只包含额度跨档提醒、低额度红色进度条及测试，可单独向上游提交PR。`personal/manual-start`在该功能之上，额外保留本机使用的启动调整、安装验证修复和桌面模式首次显示修复。fork的`main`保持上游原样。

## 改动

- `打开GPT娘.cmd`直接调用`runtime/start-widget.ps1`，不经过VBS启动器，不指定`ExecutionPolicy Bypass`，不创建计划任务或开机快捷方式。命令窗口会随挂件运行，关闭该窗口会结束挂件。
- 插件安装验证只查询`gpt-niang-local`本地市场，不再为了确认本地插件而请求全局远程插件目录。
- 首次显示窗口后再计算桌面边界，修复已保存桌面模式时首次启动的`PointToScreen`错误。

## 适用范围与使用方式

此方案适用于已有有效`gpt-niang-usage/installation.json`的安装目录，包括插件注册已经成功、但随后在验证或任务注册阶段中断的情况。该文件包含本机路径，不随仓库分发。此分支没有新增从零配置的手动安装器。

保留Node.js、Codex以及项目原有的登录与权限要求。不要改变系统执行策略或杀毒防护设置来强行运行。

1. 退出旧挂件，备份个人偏好。
2. 移除仅属于GPT娘的登录启动快捷方式和计划任务。快捷方式名为`GPT Niang Usage.lnk`，任务名为`GPT Niang Usage - <当前用户SID>`。已经中断且没有创建成功的项目无需移除。不要删除其他应用的启动项目。
3. 在挂件的更新菜单中关闭自动更新，避免官方更新覆盖本地修改。关闭自动更新是本机偏好，不是本分支强制修改的默认值。手动安装官方更新也可能恢复官方启动流程。
4. 双击本分支的`打开GPT娘.cmd`启动。退出挂件或重启系统后，需要再次手动启动。

原`安装GPT娘.cmd`和`Install.ps1`仍保留官方安装逻辑，会配置登录启动和后台任务，不属于本方案的手动启动入口。不要为打开已经配置好的挂件而重新运行安装器。

## 拦截记录与验证边界

本机先遇到解压阶段对两个开发测试脚本的`HEUR:Trojan.PowerShell.Agent.c`检测，又遇到执行`Install.ps1`时的`PDM:Trojan.Win32.Generic`行为拦截。修改为手动启动后，本机挂件能正常显示、读取额度，使用者确认当次没有新的拦截。

上述观察只说明这台机器当次运行成功，不构成对整个项目的安全认证。应把原始报毒记录和可复现步骤另行反馈给项目维护者或卡巴斯基，具体规则命中原因仍需厂商确认。

按使用者要求，本分支删除已被卡巴斯基拦截的`host-occlusion.test.ps1`、`occlusion-reminder.test.ps1`以及已无调用的`tests/fixtures/occlusion-cover.ps1`，并同步移除对应的Windows测试入口。额度功能分支保留上游测试文件，供上游PR独立审阅。

本分支也删除插件子目录内重复的安装、打开、停用CMD入口。使用根目录的入口即可，其中根目录的“打开GPT娘.cmd”为手动启动方式。

Windows发布包不再收录开发测试目录、Git忽略规则和仅供Mac聊天速度面板使用的`runtime/thread-speed.mjs`。其余仍有用途的开发测试与Mac辅助脚本继续保留在仓库中。素材来源、版权和许可说明继续随包保留。
